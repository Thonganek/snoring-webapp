# ระบบคัดกรองเด็กนอนกรน — Supabase

หน้าเว็บหลักคือ **`index.html` ที่โฟลเดอร์ราก** รวม HTML, CSS และ JavaScript ไว้ด้วยกัน เรียก API ผ่าน `/api` บนเซิร์ฟเวอร์ของเว็บไซต์ ซึ่งส่งต่อไปยัง Supabase Edge Function ข้อมูลเก็บใน Supabase PostgreSQL และวิดีโอเก็บใน Supabase Storage

```text
index.html                        หน้าเว็บหลัก
app-config.js                     Project URL และ public key สำหรับหน้าเว็บ
Supabase/
  config.toml                     ตั้งค่า Edge Function
  .env.example                    ตัวอย่าง secrets ฝั่ง backend
  migrations/                     SQL ฐานข้อมูลและ private video bucket
  functions/snoring-api/
    index.ts                      จุดเริ่มต้น Edge Function
    handler.js                    HTTP, CORS และ API ที่อนุญาต
    app.js                        ลงทะเบียน เข้าสู่ระบบ แบบประเมิน และวิดีโอ
  README.md                       คู่มือติดตั้ง
scripts/                          เปิดหน้าเว็บและตรวจไฟล์
tests/                            ทดสอบระบบ Supabase
```

## เริ่มใช้งาน

1. ติดตั้งฐานข้อมูลและ Deploy Edge Function ตาม [คู่มือ Supabase](Supabase/README.md)
2. ใส่ Project URL และ publishable key ใน `app-config.js` ห้ามใส่ secret key
3. เปิดหน้าเว็บด้วย Node.js 22 ขึ้นไป:

```powershell
npm ci
npm start
```

เปิด `http://localhost:5173` หรือ `http://127.0.0.1:5173` ห้ามเปิดด้วยการดับเบิลคลิกไฟล์ `index.html` เพราะ API ต้องทำงานผ่านเซิร์ฟเวอร์

เว็บไซต์ผ่าน GitHub Pages: https://thonganek.github.io/snoring-webapp/

เว็บไซต์ผ่าน Sites: https://snoring-child-screening.jarunyoo.chatgpt.site

สำหรับ GitHub Pages ให้รัน `npm run build:pages` แล้วนำไฟล์ใน `dist-pages/` รวมโฟลเดอร์ `assets/` (รวม 6 ไฟล์) ไปไว้ที่รากของ branch `gh-pages` ตั้งค่า Pages ให้เผยแพร่จาก branch นี้ `/` ตัว build จะตั้งให้เรียก Supabase Edge Function โดยตรง และต้องเพิ่ม `https://thonganek.github.io` ใน `APP_ALLOWED_ORIGINS` ของ Supabase ส่วนฐานข้อมูลและวิดีโอยังคงอยู่ใน Supabase พร้อมตรวจสิทธิ์ตามเดิม ห้ามนำไฟล์รหัสผ่านหรือ `.env` ไปใส่ใน branch นี้

## จัดการข้อมูลเด็ก

ใน Dashboard → ข้อมูลเด็ก เจ้าหน้าที่ใช้ปุ่ม **เพิ่มข้อมูลเด็ก** และ **แก้ไข** เพื่อบันทึกทะเบียน ชื่อ วันเกิด อายุ น้ำหนัก ส่วนสูง ขนาดทอนซิล ผลอะดีนอยด์ และหมายเหตุ ระบบคำนวณ BMI ตามสูตรเดิม การแก้ทะเบียนคงเลขบัตร บัญชีผู้ปกครอง ประวัติผลคัดกรอง โรคร่วม และประเภทข้อมูลจริง/ทดสอบไว้

admin มีปุ่ม **ลบ** พร้อมแสดงชื่อเด็กก่อนยืนยัน การลบเป็นการย้ายไปถังขยะ ไม่ทำลายประวัติหรือไฟล์วิดีโอ เจ้าหน้าที่จะไม่เห็นข้อมูลที่ลบในการใช้งานทั่วไปและรายงาน Excel admin ใช้ **ถังขยะ / กู้คืน** เพื่อนำเด็กและประวัติทั้งหมดกลับมาได้ ฐานข้อมูลปรับสถานะเด็ก ผลคัดกรอง และวิดีโอในธุรกรรมเดียว พร้อมป้องกันการเพิ่มประวัติให้เด็กในถังขยะและบันทึกกิจกรรมของผู้ดำเนินการ

ต้องรัน migration `202609050003_child_trash.sql` ก่อน deploy Edge Function รุ่นนี้

## รายงาน Excel

เจ้าหน้าที่เข้าสู่ Dashboard แล้วกด **รายงาน Excel** เลือกข้อมูลทั้งหมด / ข้อมูลจริง / ข้อมูลทดสอบ และช่วงวันที่คัดกรองตามเวลาไทย (เว้นว่างเพื่อรวมทุกวัน) แล้วกดดาวน์โหลด ระบบอ่านข้อมูลครบจาก Supabase ไม่จำกัดตามหน้าตารางหรือ 100 รายการล่าสุด และบันทึกกิจกรรมการส่งออก

รายงานประกอบด้วยสรุปผู้บริหาร ความเสี่ยง สถานะ แนวโน้มรายเดือน ประชากรเด็ก สรุปคำตอบและปัจจัย ข้อมูลเด็ก ผลคัดกรองทุกครั้ง คำตอบทุกข้อ เคสที่ต้องติดตาม วิดีโอ คุณภาพข้อมูล และนิยาม/สารบัญ รวม 13 ชีตสำหรับทีมคลินิก ผู้ดูแลระบบมีชีตผู้ใช้เพิ่ม และเลือกแนบบันทึกกิจกรรมได้ รวมสูงสุด 15 ชีต

จำนวนเด็กนับไม่ซ้ำแยกจากจำนวนครั้ง ผลล่าสุดหมายถึงล่าสุดภายในช่วงที่เลือก สถานะและทะเบียนเป็นค่าปัจจุบัน ข้อมูลทดสอบกำกับด้วย `consentVersion = demo-data` รายงานระบุสัดส่วนและตัวหารชัดเจน วันที่ในไฟล์เป็น ค.ศ. เวลาไทย ไม่แทนคำตอบที่ขาดด้วยคำตอบว่าไม่ใช่ และไม่เปลี่ยนคะแนนหรือเกณฑ์เดิม

ไฟล์สร้างในเบราว์เซอร์เป็น `.xlsx` พร้อมตัวกรอง ตรึงหัวตาราง และรูปแบบพิมพ์ ไม่ส่งออกรหัสผ่าน โทเคน เลขบัตรประชาชนจริง หรือ URL วิดีโอที่ให้สิทธิ์เข้าถึง ข้อมูลผู้ใช้และกิจกรรมตรวจสิทธิ์ admin ที่ API เก็บรายงานที่ดาวน์โหลดแยกจากไฟล์เผยแพร่เว็บไซต์เสมอ

สำหรับ Sites ให้รัน `npm run build:site` แล้วเผยแพร่ผลลัพธ์ใน `dist/` พร้อม Worker ที่ `dist/server/index.js` ซึ่งให้บริการ `/api` ด้วย การอัปโหลดเฉพาะไฟล์ HTML ไปยัง static hosting จะไม่เพียงพอ เซิร์ฟเวอร์ส่งต่อเฉพาะ JSON และ public key ไปยัง Supabase โดยไม่ส่ง cookie หรือรหัสอนุญาตของเว็บไซต์

## ทดสอบ

```powershell
npm run verify
```

ชุดทดสอบรัน SQL บน PostgreSQL ผ่าน PGlite และตรวจ Edge handler / workflow โดยจำลอง REST transport และ Storage ยังต้องทดสอบกับ Supabase cloud ของคุณหลังตั้งค่า โดยเฉพาะการอัปโหลดวิดีโอ

ระบบเข้าสู่ระบบใช้บัญชีและ session ของแอปในฐานข้อมูล Supabase ไม่ได้ใช้ Supabase Auth ผู้ปกครองใช้ข้อมูลเด็กตามแบบฟอร์ม ส่วนบัญชีเจ้าหน้าที่หลักกำหนดใน Edge Function secrets
